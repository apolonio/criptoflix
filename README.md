# CriptoFlix

O site publicado em https://criptoflix.com.br está em [`site/`](site/).

- `site/dist/index.html`: página inicial
- `site/dist/styles.css`: estilos
- `site/dist/script.js`: interações
- `site/.openai/hosting.json`: configuração do projeto no ChatGPT Sites

O arquivo `index.html` na raiz já existia neste repositório e foi preservado. Para visualizar o site localmente, abra `site/dist/index.html` no navegador ou sirva a pasta `site/dist` com um servidor estático. Alterações no GitHub não atualizam automaticamente o site hospedado no ChatGPT Sites.
